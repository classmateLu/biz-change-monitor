业务数据变了什么，机器替你盯着 本页为模拟数据演示

A business data change monitoring and reconciliation automation tool. 本页所有数据均为虚构；Diff 引擎、快照与校验为仓库真实代码运行结果（2026-10-06）。

解决什么问题

业务对象的 ID 稳定、属性天天变：价格调了、名字改了、适用门店加减了。靠人肉对账，一百个 ID 就是灾难。

怎么解决

每天自动采集 → 存快照 → 和昨天比对 → 只把「变了什么」报给你。检测引擎是纯函数，不依赖浏览器和网络。

怎么试

克隆仓库后 python main.py 即可跑通全链路（虚构数据、dry-run、零账号零配置）。往下看效果。
